# Calculatrice Santé

## Description
La **Calculatrice Santé** est un projet développé dans le cadre d'un projet étudiant à l'ENSICAEN par **Antony HUYNH**. Cette application a pour objectif de fournir une interface intuitive permettant de calculer les apports nutritionnels d'aliments consommés, tout en utilisant des fonctionnalités modernes et des pratiques de développement adaptées.

---

## Fonctionnalités principales

- **Calcul des apports nutritionnels :**
  - Analyse les aliments saisis par l'utilisateur (par exemple : "100g de poulet, 200g de riz") pour fournir des informations détaillées (calories, protéines, glucides, lipides, etc.).
- **Appels API :**
  - Utilise l'API **CalorieNinjas** pour obtenir des données précises et à jour sur les aliments.
- **Gestion des données :**
  - Les données nutritionnelles peuvent être enregistrées localement grâce à la base de données **Room**.
- **Interface utilisateur moderne :**
  - Respecte les principes **MVVM** pour une architecture propre et maintenable.
  - Responsive et compatible avec les orientations verticales et horizontales.
- **Multilingue :**
  - Disponible en **français**, **anglais** et **vietnamien**.

---

## Technologies utilisées

- **Langage principal :** Java
- **Base de données locale :** Room Database
- **API externe :** CalorieNinjas
- **Architecture :** MVVM (Model-View-ViewModel)
- **Outils supplémentaires :**
  - Threads/Services pour les appels API.
  - Support des layouts adaptatifs (Responsive Design).
---

## Installation
- Installer CalculatriceSante.apk depuis son téléphone Android

- Minimum Android 7.0 (Nougat)
